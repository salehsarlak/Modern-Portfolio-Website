## ✨ Features

- 🎨 **Modern Dark Theme** with elegant purple accents (`#c778dd`)
- 📱 **Fully Responsive** — looks perfect on mobile, tablet & desktop
- ⚡ **Lightning Fast** — pure HTML & CSS, zero JavaScript frameworks
- 🧭 **Smooth Navigation** with fixed header + social sidebar
- 📄 **Multi-page Structure**:
  - Home / Hero
  - Projects
  - About Me
  - Contact
- 🔤 Beautiful **Fira Code** font
- 💫 Clean, minimal & professional design

---

## 🛠️ Tech Stack

| Technology | Description |
|------------|-------------|
| **HTML5** | Semantic & accessible markup |
| **CSS3** | Flexbox, custom properties, modern layout |
| **Fira Code** | Variable font for beautiful typography |
| **Pure CSS** | No frameworks, no build step |
